# 🍿 Telegram Cinema Bot + Web App (Mini App)

Полноценный готовый комплекс: **Telegram-бот для продажи подписок** + **встроенный онлайн-кинотеатр (Telegram Web App)** с каталогом, поиском и плеером (Kinobox, Kodik, Collaps, Videocdn, Alloha).

---

## 🌟 Возможности проекта

1. **Telegram-бот (Aiogram 3)**:
   - Автоматический расчет стоимости и выдача реквизитов банковской карты для прямого перевода.
   - Прием скриншотов чеков / PDF-квитанций об оплате от пользователей (FSM).
   - Мгновенная пересылка чеков администраторам с кнопками: `[✅ Одобрить 30 дней]`, `[✅ Одобрить 90 дней]`, `[❌ Отклонить]`.
   - Автоматическое начисление дней подписки при подтверждении и уведомление пользователя.
   - Панель администратора (`/admin`): статистика пользователей, выручки, ручная выдача доступа (`/give`) и рассылка (`/broadcast`).

2. **Онлайн-кинотеатр (Telegram Web App / Mini App)**:
   - Современный мобильный интерфейс в темной теме (без лишней нагрузки и тяжелых библиотек).
   - Фильтрация по категориям (Фильмы, Сериалы, Мультфильмы, Аниме).
   - Умный поиск с автодополнением и онлайн-каталогом.
   - Встроенный плеер (Kinobox): автоматический поиск источников (Kodik, Alloha, Collaps, Videocdn, HDRezka), выбор русской озвучки, качества 1080p/4K, сезонов и серий.
   - Проверка VIP-статуса пользователя.

3. **База данных**:
   - Асинхронный SQLite (`aiosqlite`) — не требует отдельной настройки, надежно хранит пользователей, подписки и историю заявок.

## 🚀 Быстрый старт и установка

python3 -m venv venv

### 2. Настройка файла `.env`

Откройте файл `.env` и укажите ваши данные:

```ini
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Ваш Telegram ID (узнать можно в боте @userinfobot)
ADMIN_IDS=123456789

# Ваши реквизиты для получения оплаты
CARD_NUMBER=2202 2000 0000 0000
CARD_BANK=Т-Банк / Сбербанк

# Стоимость и срок подписки
SUBSCRIPTION_PRICE=299
SUBSCRIPTION_DAYS=30

# Ссылка на WebApp (см. пункт 3 ниже)
WEBAPP_URL=http://localhost:8000
```

## 🌐 Как открыть WebApp внутри Telegram (HTTPS)

Telegram Web App **требует HTTPS-ссылку** для открытия внутри мобильного приложения.

### Вариант для локальной разработки (ngrok или Cloudflare Tunnel):
1. Запустите в отдельном терминале:
   ```bash
   ngrok http 8000
   ```
   *или с помощью Cloudflare Tunnel (бесплатно без регистрации):*
   ```bash
   npx cloudflared tunnel --url http://localhost:8000
   ```
2. Скопируйте полученную ссылку `https://xxxx.ngrok-free.app` (или `https://xxxx.trycloudflare.com`).
3. Вставьте её в `.env` в параметр `WEBAPP_URL=https://xxxx.ngrok-free.app`.

### Вариант для сервера (VPS / Production):
Направьте домен на ваш VPS (например, `cinema.yourdomain.com`), настройте Nginx с SSL-сертификатом от Let's Encrypt (Certbot), и укажите адрес в `WEBAPP_URL`.

## ▶ Запуск приложения

Запустите проект одной командой:

```bash
python3 run.py
```

После запуска:
- **FastAPI WebApp** будет доступен по адресу: `http://localhost:8000` (можно открыть прямо в браузере для тестирования дизайна и плеера).
- **Telegram-бот** начнет принимать сообщения и команды от пользователей.

## 📱 Сценарий работы (User Flow)

1. Пользователь заходит в бота и жмет `/start`.
2. Нажимает **«💳 Купить доступ в кинотеатр»**.
3. Бот присылает номер карты и сумму. Пользователь переводит деньги и нажимает **«📤 Я оплатил (Отправить чек)»**.
4. Пользователь отправляет фото чека.
5. Бот пересылает чек администратору в чат с кнопками `[✅ Одобрить 30 дней]` и `[❌ Отклонить]`.
6. Администратор нажимает **Одобрить**.
7. Пользователь получает уведомление о подтверждении и постоянную кнопку **«🎬 Открыть кинотеатр»** (Web App), где сразу может смотреть любые фильмы и сериалы в HD качестве!
